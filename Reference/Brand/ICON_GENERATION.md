# Nouvelle icône Cadence

Cette création est conservée pour le nouveau nom **Cadenza** : le symbole C ne contient aucun mot à remplacer. Le prompt original ci-dessous est conservé tel qu’il a été envoyé à imagegen.

Outil : image_gen intégré (imagegen), génération originale sans image source.
L’image originale est conservée dans ce dossier ; le PNG AppIcon est exporté en 1024 × 1024 RGB opaque pour iOS.

Prompt final :

Use case: logo-brand. Asset type: production iOS app icon, square 1024 x 1024 opaque full-bleed artwork for a French premium study time app called Cadence. Create ONE finished icon, not a contact sheet, not a mockup. Main subject: a distinctive single flowing cobalt-blue translucent glass ribbon forming a graceful near-circular letter C, open at upper-right. The lower-left inner turn subtly evokes a folded book page; the circular negative space suggests the rhythm of time without literal clock hands or numerals. Sculptural but very simple silhouette, thick continuous ribbon, readable at 40px. Premium recent Apple-like polished glass, precise soft refraction, icy cyan edge highlights and deep electric blue core; refined restrained dimensionality. Centered, balanced, symbol takes 65 percent of square, generous uncluttered breathing space. Background: very pale blue-white full square with gentle diffuse sky-blue light halo, soft contact shadow. No pre-rounded corners, iOS applies its own mask. No text, no lettering besides the C-shaped symbol, no word Cadence, no typography, no extra badges, no sparkles, no stars, no purple, no phone, no frame, no watermark, no busy texture. Elegant confident original visual identity, subtle glass effects, never a generic SF book icon.
